# OnePlus Discover Manager

Automated ADB utility to disable, enable, or replace Google Discover with Shelf on OnePlus/Oppo/Realme devices.

## Features

- Automatic ADB download
- Automatic device detection
- USB debugging detection
- Enable Google Discover
- Disable Google Discover
- Replace Discover with Shelf
- Automatic reboot
- Beginner-friendly automation

## Requirements

- Windows PC
- USB cable
- USB Debugging enabled

## Usage

Run:

```bat
start.bat
```

The tool automatically:
- downloads ADB
- waits for your device
- detects authorization
- applies selected option

## Supported Devices

- OnePlus (Tested on oxygen os 16)
